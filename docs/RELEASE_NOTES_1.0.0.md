PagePress 1.0.0 personal beta

Save the current webpage as a PDF on your device. This release includes full-page and viewport visual capture, a separate browser-print mode, page cleanup, A4/Letter settings, source/date footers, saved presets, progress, cancellation, and a quick-save keyboard shortcut.

Download the ZIP, extract it, and use Chrome's Extensions page → Developer mode → Load unpacked. Keep the extracted folder in place. The installation guide and working sample PDF demo are at https://pdf.mulhamkassab.dev/install.

Visual PDFs preserve the page's appearance as images. Use Print PDF for selectable text where the website supports it. Protected pages and some long or changing layouts have browser limitations.

Validated with 23 automated regression tests, isolated real-Chromium capture/download checks, rendered PDF inspection, and desktop/mobile demo checks. Processing is local; the production extension requests temporary active-tab access, with no persistent all-site or debugger permission.

This beta is not yet listed in the Chrome Web Store. Store listing preparation and permission explanations are in docs/CHROME_WEB_STORE.md.
