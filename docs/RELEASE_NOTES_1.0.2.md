PagePress 1.0.2 personal beta

PagePress now lives at https://webtopdf.mulhamkassab.dev/. Extension home and help links use the new address. The old pdf.mulhamkassab.dev address redirects to the new site, keeping previous bookmarks and links working.

Download the ZIP, extract it, then use Chrome's Extensions page → Developer mode → Load unpacked. Keep the extracted folder in place. Existing unpacked installations can replace their extracted files and click Reload. Installation help: https://webtopdf.mulhamkassab.dev/install.

Capture behavior and permissions are unchanged. Visual PDF exports preserve appearance as images; use Print PDF for selectable text where supported. Processing remains local.

The beta is not yet listed in the Chrome Web Store.
