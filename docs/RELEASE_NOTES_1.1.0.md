webTopdf 1.1.0 — by Mulham Kassab

The extension is now named webTopdf. Its popup credits Mulham Kassab and links to https://mulhamkassab.dev/. The Chrome extension homepage uses that address too.

Save a full webpage or its current view as a PDF on your device, with browser-print mode, page cleanup, A4/Letter settings, and a quick-save shortcut. Visual PDF captures preserve appearance as images; browser print can preserve selectable text where the source page supports it.

The website and portfolio use the new name. Download and installation help: https://webtopdf.mulhamkassab.dev/.

Verified with 24 regression tests and browser checks. Chrome Web Store listing materials are included in the repository's store/ folder and docs/CHROME_WEB_STORE.md. Store submission remains pending; this release does not claim store approval.
