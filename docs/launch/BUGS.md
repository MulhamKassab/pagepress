# webTopdf — bug and risk list (launch audit, 18 Nov 2026)

Audited code: `codex/pagepress` = `main` = `74e12d7`. The extension folder matches tag `v1.1.0` (`9afe4f1`), which is very likely the store's 1.1.0; the store package itself was not compared. Nothing here has been fixed; this list is for planning. Plan: [LAUNCH-PLAN.md](LAUNCH-PLAN.md).

**How found**
- *Repro (Edge)*: reproduced with a scratch Playwright harness (kept outside the repo) on local fixture pages, in Microsoft Edge with a throwaway profile. The harness used a test copy of the extension with an `<all_urls>` grant, because a script cannot press the toolbar button. Engine behaviour (scrolling, measuring, capture, PDF assembly) is the same as in production; anything that depends on `activeTab` or on Chrome specifically is marked at most Likely.
- *Check*: a local command failed or flagged it.
- *Live*: seen on the live website or the public store page.
- *Code*: code reading only.

**Confidence**: Confirmed = reproduced; Likely = strong code evidence, not reproduced; Possible = plausible, needs a test.

**Blockers: none found.** The extension works on ordinary pages, permissions are minimal, and the store already accepted it. The High items are the ones that make users leave 1-star reviews.

## Not checked

- **Store package**: the ZIP uploaded to the Chrome Web Store was not downloaded or compared. The store says version 1.1.0 / 161 KiB / updated 13 Oct 2026, and the GitHub v1.1.0 release ZIP comes from `9afe4f1`; matching them is an inference.
- **Real Chrome with `activeTab`**: there is no branded Chrome on this PC, and Playwright's Chromium is blocked. Everything ran in Edge with a test-only host grant. The toolbar-click → `activeTab` path, the Web Store page, `file://` pages and Chrome's own PDF viewer were not exercised.
- **Lazy-image pixels (WT-05)** and **memory limits (WT-11)**: the produced PDFs were not inspected image by image, and no stress test was run on a 100k px page.
- **Contrast and screen-reader pass** on the popup and website (no axe or Lighthouse run).
