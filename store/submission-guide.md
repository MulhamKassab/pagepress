# Submit webTopdf

This folder contains the prepared listing and graphics. The ready-to-upload extension is `webtopdf-extension-v1.1.0.zip`, included with the submission kit and GitHub release. Upload that extension ZIP, not the outer submission-kit ZIP. Its `manifest.json` is at the archive root.

1. Open https://chrome.google.com/webstore/devconsole/ in Chrome and sign in to your publisher account. Complete any required account registration, legal agreements, or registration payment yourself.
2. Use **Add new item**, upload `webtopdf-extension-v1.1.0.zip`, and fill the listing with `listing.txt`. Desired publisher display name: **Mulham Kassab**. Homepage: **https://mulhamkassab.dev/**.
3. Add `icon128.png`, `screenshot-capture.png` (1280×800), and `promo-small.png` (440×280). The images show the actual interface and your name/website.
4. Complete the privacy and distribution fields using `privacy-and-permissions.txt`. Select free/public distribution in the regions you wish to support.
5. Save the draft and use **Submit for review**. Choose automatic publication after approval if you want it released when Google's review succeeds. A submitted item is not yet an approved store listing.

The website still offers manual installation while store approval is pending. After approval, update the site's download button to the verified Chrome Web Store listing URL.

Official publishing instructions: https://developer.chrome.com/docs/webstore/publish.
