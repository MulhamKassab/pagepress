BEFORE YOU PRESS

A few
good questions.

No magic promises. Just a practical way to save the web.

Can it export any website?+

It works on ordinary webpages that Chrome allows extensions to access. Chrome’s settings, the Web Store, and some protected pages are restricted. Long pages, embedded frames, sticky elements, and content that appears only as you scroll can affect a full-page capture.

Will I be able to search the PDF?+

A visual capture saves the page as images, so its text is not selectable or searchable. For text documents, try the separate browser-print action. Chrome’s print output depends on how that website is built.

Does anything leave my device?+

PagePress processes captures and PDFs locally. The extension has no account, upload service, or analytics. The companion website also uses no analytics or third-party fonts. Your browser still loads the original website as usual.

How do I install it today?+

Download the extension ZIP, extract it, then open chrome://extensions. Turn on Developer mode and choose Load unpacked to select the extracted extension folder. This release is installed manually; there is no Chrome Web Store listing yet. See the step-by-step guide.

What about very long or changing pages?+

Load the content you need before exporting. For infinite feeds, large documents, or virtualized lists, capture a smaller section or use the current-view option. A screenshot records the visible rendering; it cannot recover content the site has removed from the page.
