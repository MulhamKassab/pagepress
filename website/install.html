Get started in 3 steps

ONE-TIME SETUP

  1. Download and extract

    Download the ZIP above and unzip it into a folder you can keep.

  2. Add it to Chrome

    Paste this into Chrome’s address bar:

    chrome://extensions

    Turn on Developer mode, click Load unpacked, and choose the extracted folder containing manifest.json.

  3. Open a page and save

    Pin PagePress from Chrome’s extensions menu. Open a webpage, click PagePress, then Save as PDF.

Visual PDF keeps the page’s appearance as images. For selectable text, choose Print PDF in the extension.

Keep the extracted folder in place. To update, replace its files and click Reload at chrome://extensions.
