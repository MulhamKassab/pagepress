Help for
webTopdf.

Quick answers to the most common questions. To install webTopdf, use the Chrome Web Store.

Add to Chrome ↗

Desktop Chrome or Edge only. Extensions do not run on phones or tablets, so open this page on a computer.

How do I install it?

Open the Chrome Web Store listing, choose Add to Chrome and confirm Add extension. Then open Chrome’s extensions menu beside the address bar and pin webTopdf. It needs Chrome 116 or newer on a computer, and also works in Microsoft Edge.

Why can’t I save some pages?

Chrome does not let any extension read its own pages (such as chrome:// pages and the new tab page), the Chrome Web Store, and some browser-owned pages and built-in PDF viewers. The popup shows a short reason for these pages instead of failing silently. For a PDF that is already open, download or print it from the viewer. Pages that need you to sign in work normally, because webTopdf reads the page you are looking at.

Image PDF or searchable PDF?

Visual PDF (Full page or Current view) keeps the exact look of the page, but as pictures, so the text cannot be selected or searched. Searchable print opens Chrome’s print preview; choose Save as PDF there to get real, selectable text. The layout then follows the website’s own print style, so it can differ from the screen.

What about very long or infinite pages?

Full page captures what is loaded when you start. Scroll down first if you need more of an endless feed to load. Very long pages take longer and use more memory; if an export fails, try Current view, a lower image quality, or Searchable print. Keep the tab open and in front until the download starts.

My page scrolls inside a panel

Some apps (mail, notes, chat and many documentation sites) keep the page fixed and scroll only an inner panel. Full page may then capture only what is on screen, or webTopdf may tell you that the page scrolls inside a panel. In that case use Current view for each screen, use Searchable print, or open the content in its own full-page view if the app offers one.

Does it work with Arabic and right-to-left pages?

Yes. Right-to-left pages can be captured, and the popup is available in English and Arabic (it follows your Chrome language). Visual PDFs keep Arabic text exactly as shown because they are images. If a footer or title looks wrong in a PDF viewer, please report it.

Does it upload my pages?

No. PDFs are built on your device. There is no account, the extension has no analytics, and no server receives page content. Read the privacy policy for details.

Getting help or reporting a problem

The popup’s Report a problem link opens a pre-filled report that contains only the extension version, your browser and the error message, never page content. For anything involving private pages, write to the developer email shown on the Chrome Web Store listing. For ordinary bugs and ideas, use the GitHub issue tracker, and please do not paste private page content there.

For developers

A manual ZIP for developers and testers is on the home page. It never updates itself, so use the Chrome Web Store version for everyday use.
