PagePress is an unpacked Chrome extension. Download it, add it to your browser, and make your first capture.

This is an early release installed through Chrome’s Developer mode. It is not listed in the Chrome Web Store yet. No subscription or account is needed.

  1. Download and extract

    Download the extension ZIP, then extract it into a folder you can keep. Keep the extracted files in place while the extension is installed.

    Download PagePress ZIP ↓
  2. Open Chrome’s extensions page

    Paste chrome://extensions into Chrome’s address bar. Turn on Developer mode using the switch at the top right.

  3. Load the extension

    Click Load unpacked and select the extracted folder containing manifest.json. If the ZIP created an outer folder, look one level inside it.

  4. Pin PagePress

    Click Chrome’s puzzle-piece extension icon, then pin PagePress. Its blue paper icon will stay in your toolbar, ready for a page worth keeping.

  5. Save your first page

    Open an ordinary webpage. Click PagePress, choose the current view or entire page, set your paper options, and start a visual PDF capture. Chrome downloads the finished file to your device.

Choose the right kind of PDF

Visual PDF keeps the browser’s rendered appearance as images. Its page text is not selectable or searchable. Use it when the look of the page matters.

Browser print opens Chrome’s print dialog. Choose Save as PDF there, then save the file. This often keeps selectable text, but the page’s print styles decide the layout.

Give long pages a moment

Load the content you need before exporting. Full-page captures may briefly scroll the page. Avoid interacting with the tab until the capture finishes. For a changing feed or a very long page, the current-view option is a useful fallback.

If a page will not capture

Chrome restricts extension access to its own settings, the Chrome Web Store, and other protected pages. Embedded frames, fixed overlays, animations, and virtualized lists can also affect the result. Try a smaller capture or the browser-print action.

Update or remove

To update, replace the extracted files with the new release and click the reload icon for PagePress at chrome://extensions. To uninstall, click Remove on the extension’s card. Your downloaded PDFs stay on your device.
